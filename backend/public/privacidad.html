Política de Privacidad

En fut.invest ("la Plataforma"), nos tomamos tu privacidad muy en serio. Esta política describe cómo recopilamos, usamos y protegemos tus datos personales.

1. Datos que Recopilamos

  • Datos de registro: nombre, email, contraseña (almacenada con hash bcrypt)
  • Datos de perfil: dirección, documento de identidad (solo KYC)
  • Datos de uso: dirección IP, tipo de navegador, páginas visitadas
  • Datos de transacciones: montos, direcciones de billetera, historial de contratos

2. Cómo Usamos tus Datos

  • Operar y mantener la plataforma de inversión
  • Verificar tu identidad (KYC)
  • Enviar notificaciones sobre transacciones y cambios de estado
  • Cumplir con obligaciones legales y regulatorias
  • Mejorar la experiencia de usuario y detectar fraudes

3. Seguridad de Datos

Implementamos las siguientes medidas de seguridad:

  • Cifrado AES-256 GCM para datos sensibles en reposo
  • TLS 1.3 para todas las comunicaciones
  • Autenticación JWT con refresh tokens y rotación
  • 2FA opcional con TOTP (RFC 6238)
  • Auditoría de acceso a datos sensibles

4. Compartición de Datos

No vendemos tus datos personales. Compartimos datos solo con:

  • Proveedores de pago (Coinbase Commerce, Stripe) para procesar transacciones
  • Autoridades regulatorias cuando sea requerido por ley

5. Retención de Datos

Conservamos tus datos mientras mantengas una cuenta activa. Tras el cierre de cuenta, conservamos datos financieros por 5 años para cumplimiento regulatorio, y eliminamos el resto después de 90 días.

6. tus Derechos

  • Acceder a tus datos personales
  • Solicitar corrección de datos incorrectos
  • Solicitar eliminación de tu cuenta y datos (sujeto a retención legal)
  • Exportar tus datos en formato CSV
  • Revocar el consentimiento para marketing

7. Cookies

Utilizamos cookies esenciales para la autenticación (JWT en localStorage). No usamos cookies de rastreo ni publicitarias. Puedes deshabilitar cookies en tu navegador, pero la plataforma no funcionará correctamente.

8. Contacto

Para ejercer tus derechos o consultar sobre privacidad, contacta a: privacidad@futinvest.io
